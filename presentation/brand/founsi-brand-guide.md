## 1. Brand Overview

### Who We Are

Founsi is the memory layer for your physical life. We use camera-based AI detection to build a living inventory of everything you own, so you never forget, lose, or rebuy what you already have.

### Mission

Eliminate the forgetting tax. The average person spends 2.5 days per year looking for lost items and wastes $2.7 billion annually replacing things they already own. Founsi makes Physical World Blindness a thing of the past.

### Vision

A world where every object you own is instantly searchable, tracked, and remembered. Your camera becomes a memory engine. Founsi becomes the system of record for your belongings.

### Brand Essence

> **"Your brain has better things to do."**

Founsi handles the tedious work of remembering what you own, where it is, and what condition it's in. We free up mental bandwidth for the things that actually matter.

## 2. Brand Personality

### Core Traits

| Trait | Description | In Practice |
|-------|-------------|-------------|
| **Confident** | We know what we built is valuable. No hedging, no "we try to." We state facts. | "Founsi catalogs, tracks, and remembers everything you own." Not "Founsi helps you try to keep track." |
| **Witty** | Smart humor, not silly. Our copy has a wink to it. We're the clever friend, not the class clown. | "Fund us so this goes faster. Just kidding. Kind of." |
| **Human** | Technology serves people. We talk about real problems (losing your drill, forgetting warranties) not abstract tech. | "Currently lent to Mike (2 weeks ago)" feels real. "Item transferred to external user" does not. |
| **Bold** | We're creating a new category. We say so. No one built the system of record for belongings. Until now. | Lead with the problem and the claim. Back it up with the demo. |
| **Trustworthy** | People are letting us see inside their homes. Privacy and trust are non-negotiable in every word we write. | "Your data stays yours. Always." is a promise, not a feature bullet. |

### Brand Voice Spectrum

```
Casual ←————————●———————→ Formal
                 ^
           We live here.
    Professional but approachable.
    Never stiff. Never sloppy.
```

### Voice Do's and Don'ts

**Do:**
- Use "you" and "your" — it's personal
- Use contractions — "we're" not "we are"
- Use concrete examples — "your power drill" not "your items"
- Use present tense — "Founsi detects" not "Founsi will detect"
- Use active voice — "We built" not "It was built"
- Use short sentences for impact. Then elaborate.

**Don't:**
- Use jargon without context (say "AI object detection" not "SAM-3 segmentation pipeline")
- Use passive voice in headlines
- Use exclamation marks in body copy (one per page max, in CTAs only)
- Overpromise — if a feature is coming soon, say "coming soon"
- Use "leverage," "utilize," "synergy," "disrupt" or any other corporate hollow words
- Reference specific technical implementations (Neo4j, SAM 3, etc.) in external-facing copy unless in a technical blog post

## 3. Logo

### Primary Logo

The Founsi wordmark uses **Syne Extra Bold** with a distinctive purple period after the name.

```
Founsi.
```

- The period is always purple (#9378FF)
- The wordmark is always in the primary text color for the context (dark on light, white on dark)
- Minimum clear space: the height of the "F" on all sides
- Minimum size: 24px font-size for digital, 12pt for print

### Logo Variants

| Variant | Usage | Text Color | Dot Color |
|---------|-------|------------|-----------|
| **Primary (light bg)** | Websites, light documents | #2E2C32 | #9378FF |
| **Inverted (dark bg)** | Dark sections, overlays | #FFFFFF | #9378FF |
| **Monochrome** | Single-color contexts (fax, embossing) | Black or White | Same as text |

### Logo Misuse

- Never stretch, rotate, or skew the wordmark
- Never change the purple dot to another color
- Never place the logo on busy backgrounds without a container
- Never add effects (drop shadow, glow, outline)
- Never retype the logo in a different font

### Color Accessibility

- Purple Primary (#9378FF) on white: **4.63:1** contrast ratio (passes AA for normal text)
- Purple Dark (#7B5EF0) on white: **5.2:1** contrast ratio (passes AA)
- Ink (#2E2C32) on white: **14.7:1** contrast ratio (passes AAA)
- Always use Purple Dark (#7B5EF0) for text on white, not Purple Primary
- Never place Purple Primary text on colored backgrounds without checking contrast

### Color Usage Rules

1. Purple is the accent, never the dominant color. A page should be ~80% white/grey, ~15% ink, ~5% purple.
2. Never use more than two purples in the same component (e.g., purple border + purple badge is fine; purple border + purple background + purple text is not).
3. Semantic colors (green, amber, red) are used only for status. Never decoratively.
4. Dark theme: If needed, use `#0F0E13` background, `#1A1920` surfaces, `#FFFFFF` text. The purple palette stays the same.

## 5. Typography

### Font Families

| Role | Font | Source | Fallback |
|------|------|--------|----------|
| **Display** | Syne | Google Fonts | system-ui, sans-serif |
| **Body** | Manrope | Google Fonts | system-ui, sans-serif |
| **Code** | Courier New | System | monospace |

### Loading

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Syne:wght@400;600;700;800&family=Manrope:wght@400;500;600;700;800&display=swap" rel="stylesheet">
```

Always use `display=swap` to prevent invisible text during font loading.

### Type Scale

| Element | Font | Weight | Size | Line Height | Letter Spacing | Color |
|---------|------|--------|------|-------------|----------------|-------|
| **Hero Headline** | Syne | 800 | clamp(28px, 5vw, 44px) | 1.05 | -1.5px | #2E2C32 |
| **Section Title** | Syne | 700 | 28-36px | 1.1 | -1px | #2E2C32 |
| **Card Title** | Manrope | 700 | 15-18px | 1.3 | 0 | #2E2C32 |
| **Body** | Manrope | 400 | 14-15px | 1.6 | 0 | #2E2C32 |
| **Body Bold** | Manrope | 600 | 14-15px | 1.6 | 0 | #2E2C32 |
| **Small / Meta** | Manrope | 500 | 12px | 1.4 | 0 | #7E7A8A |
| **Caption** | Manrope | 600 | 11px | 1.2 | 0.5px | #655E74 |
| **Badge** | Manrope | 700 | 11px | 1.0 | 0 | #9378FF |
| **Overline** | Syne | 700 | 12px | 1.0 | 3px | #9378FF |
| **Button** | Manrope | 700 | 14px | 1.0 | 0 | #FFFFFF (on purple) |
| **Code** | Courier New | 400 | 13px | 1.5 | 0 | #2E2C32 |

### Typography Rules

1. **Syne is for display only.** Headlines, titles, the logo, and overlines. Never body text.
2. **Manrope is for everything else.** Body, buttons, labels, inputs, tooltips, badges.
3. **Never use more than 3 font weights on a single screen.** Typical combo: Syne 800 (headline) + Manrope 400 (body) + Manrope 700 (labels/buttons).
4. **Headings are tight.** Use negative letter-spacing (-1px to -1.5px) on Syne headlines.
5. **Body is loose.** Use 1.6 line-height for readability in paragraphs.

## 6. Spacing & Layout

### Spacing Scale

```
4px   (xs)    — Inner padding of dense elements (badge text)
8px   (sm)    — Gap between inline elements, icon padding
16px  (md)    — Standard gap between related elements
24px  (lg)    — Section internal padding, card padding
32px  (xl)    — Gap between sections within a page area
48px  (2xl)   — Major section breaks
64px  (3xl)   — Page section spacing
80px  (4xl)   — Hero/footer top-bottom padding
```

### Border Radius Scale

```
6px   (sm)    — Tags, small badges, pills
10px  (md)    — Buttons, inputs
14px  (lg)    — Cards, panels
16px  (xl)    — Image containers, modals
20px  (2xl)   — Upload zones, hero cards
9999px (full) — Circle buttons, dots, avatars
```

### Grid System

- **Max content width:** 880px
- **Page horizontal padding:** 24px (desktop), 16px (mobile)
- **Card grid:** CSS Grid, `repeat(auto-fill, minmax(160px, 1fr))`, 12px gap
- **Stack layout:** Flexbox column, 10px gap
- **Two-column detail rows:** Flexbox row, space-between

## 7. Shadows & Elevation

| Level | Value | Usage |
|-------|-------|-------|
| **sm** | `0 1px 3px rgba(0,0,0,.04)` | Default card resting state, subtle lift |
| **md** | `0 2px 8px rgba(0,0,0,.05)` | Active cards, dropdowns, tooltips |
| **lg** | `0 8px 24px rgba(147,120,255,.1)` | Hover state on cards, focused inputs |
| **xl** | `0 12px 32px rgba(147,120,255,.15)` | Modals, floating panels, popovers |

### Shadow Rules

1. Shadows are always subtle. If you can obviously see the shadow without squinting, it's too strong.
2. Purple-tinted shadows (lg, xl) are used only on interactive elements on hover or focus. Never on resting state.
3. No inner shadows. No text shadows. No drop shadows on images.

## 11. Imagery & Photography

### Style Direction

- **Real spaces, real objects.** Not stock photos of smiling people pointing at screens.
- **Warm, natural lighting.** As if taken with an iPhone in good light.
- **Lived-in environments.** Kitchens with spice racks, garages with tools, desks with cable clutter. Aspirational but relatable.
- **No overlays on photos.** Founsi does not draw bounding boxes, highlights, or annotations on user photos. The image stays clean. Always.

### Placeholder / Sample Scene Style

When generating sample scenes (for demos where real photos aren't available):

## 12. Motion & Animation

### Principles

1. **Every animation has a purpose.** It either communicates state change, guides attention, or provides feedback. Never decorative motion.
2. **Fast in, slow out.** Use `cubic-bezier(.16, 1, .3, 1)` for elements entering the viewport.
3. **Respect the user.** If `prefers-reduced-motion` is set, disable all non-essential animations. Show static states instead.

### Animation Library

| Name | CSS | Duration | Easing | Usage |
|------|-----|----------|--------|-------|
| **fadeIn** | opacity 0 → 1 | 300ms | ease | Page sections, overlays appearing |
| **fadeInUp** | translateY(30px) + opacity | 500ms | ease | Scroll-reveal for sections |
| **slideUp** | translateY(40px) + opacity | 500ms | cubic-bezier(.16,1,.3,1) | Cards entering viewport |
| **stackSlide** | translateX(-30px) + opacity | 500ms | cubic-bezier(.16,1,.3,1) | Result cards cascade |
| **scanDown** | top: 0 → 100% | 3.5s | ease-in-out, infinite | Scan line during processing |
| **breathe** | scale(1) → 1.12, opacity .5 → .85 | 2s | ease, infinite | Loading icon pulse |
| **popIn** | scale(0.4) → 1.06 → 1 | 500ms | cubic-bezier(.16,1,.3,1) | Items appearing with bounce |
| **countPop** | scale(0) → 1.3 → 1 | 500ms | cubic-bezier(.16,1,.3,1) | Countdown numbers |
| **ringPulse** | scale(1) → 2.5, opacity .6 → 0 | 1.5s | ease, infinite | Spotlight indicator ring |

### Transition Defaults

```css
/* All interactive elements */
transition: all 0.2s ease;

/* Card expand/collapse */
transition: all 0.3s ease-in-out;

/* Color/opacity changes */
transition: opacity 0.5s, color 0.2s;
```

## 15. Accessibility Standards

### Requirements (WCAG 2.1 AA)

- All text meets 4.5:1 contrast ratio against its background
- All interactive elements are keyboard-navigable (Tab, Enter, Space, Escape)
- Focus indicators: 2px solid #9378FF outline, 2px offset
- Screen reader support: aria-labels on all interactive elements, aria-live regions for dynamic content
- Respect `prefers-reduced-motion` — disable animations, show static alternatives
- Alt text on all images. Decorative images get `alt=""`
- Touch targets: minimum 44x44px on mobile
